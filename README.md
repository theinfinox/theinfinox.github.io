## Aesthetic & Architecture

Designed using **Google Stitch** following the **Obsidian Terminal** design system:
- **Palette**: Deep void canvas (`#09090b` / `#121215`), high-contrast crisp text (`#d4d4d8` / `#ffffff`), muted metadata (`#71717a`), and phosphor green accent (`#22c55e`).
- **Typography**: [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) across all hierarchies.
- **Styling**: Tailwind CSS with custom terminal tokens.
- **Features**: Live IST clock synchronization, real-time telemetry card for PiCloud, curated project highlights, experience timeline, and verified SEO / OpenGraph tags.
